# THE LEGACY

THE LEGACY est un écosystème numérique international consacré
à l'éducation, à la connaissance, à l'autonomie et au développement humain.

## Principes
- Accessibilité et apprentissage gratuit.
- Architecture modulaire et évolutive.
- Protection de la vie privée et sécurité.
- Transparence et esprit critique.
- Respect des personnes et des droits d'auteur.

## Architecture
Le projet repose sur un noyau central et des modules indépendants.

## Modules
1. ACADEMY
2. KNOWLEDGE
3. LANGUAGES
4. HEALTH
5. SPORTS
6. WEALTH
7. TALENTS
8. TECHNOLOGY
9. GLOBAL
10. COMMUNITY
11. AVATAR

## Installation
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e ".[dev]"
```

## Tests

pytest
