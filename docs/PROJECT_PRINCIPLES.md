# Principes fondamentaux

1. L'apprentissage doit être accessible.
2. Les informations doivent être vérifiables et contextualisées.
3. Les données personnelles doivent être protégées.
4. Aucun rendement financier ne doit être garanti.
5. Les contenus de santé sont éducatifs et ne remplacent pas les professionnels.
6. Les activités sportives doivent être adaptées aux capacités de chacun.
7. Les droits d'auteur et les licences doivent être respectés.
8. La sécurité des mineurs est une priorité.
9. Les membres gardent le contrôle de leurs données et préférences.
10. Les modules doivent pouvoir évoluer indépendamment.
