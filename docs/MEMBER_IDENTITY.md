# Identité des membres

Chaque membre possède un identifiant THE LEGACY indépendant de Discord.

## Principes
- Identifiant interne unique.
- Liaison externe facultative avec Discord.
- Aucun nom civil requis pour le fonctionnement ordinaire.
- Aucun mot de passe ou jeton Discord stocké dans cette table.
- Langue préférée modifiable.
- Statut de compte contrôlé.
- Données minimales et accès limités.

## Évolution
Cette identité devra rester compatible avec le futur site web,
l'application mobile et les autres intégrations.

Les mécanismes d'authentification seront conçus séparément.
